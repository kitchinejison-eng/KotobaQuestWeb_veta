# KotobaQuest V82 One Screen Complete (Browser)

## 統合内容
- V80のブラウザ版プロジェクトをベースに、保存済みV81/V82更新パッチを順に適用。
- betatest.9で調整した1画面レイアウト、記録カレンダー、基礎トレーニングの単語→短文・アクセント表示を統合。
- トレーニング記録・ドリル印刷・ことばクエストZ・コトバファンタジーDX・ことばダンジョンを専用画面用スタイルで再配置。
- V82モーラ練習のスタイル選択は「手拍子」「画面タップ」の2方式を維持し、1画面に収める表示に調整。

## 1画面設計
画面全体は固定し、記録一覧・問題選択肢・ドリルプレビューなど長い内容だけを内部スクロールさせます。主要な回答・録音・判定・次へ進む操作を画面内に残す構成です。

## 起動
`index.html`をWebサーバーまたはHTTPSで開いてください。マイク機能はブラウザーの権限とHTTPS環境が必要です。

## 検証範囲
JavaScript構文、HTML構造、CSS構文、参照ファイル、ZIP整合性を検査しています。すべての端末・画面サイズでの実機表示、ブラウザー音声認識、プリンター接続は別途確認が必要です。
