# ことクエ V84 画面調整パッチ

- タイトル画面はV82以前の元デザインへ復元（「モバイル版」バッジ・短縮ロゴ表示を撤去）。
- Androidランチャー名「ことクエ」と本番版との独立IDは維持。
- ドリル印刷の設定パネル・ジャンル一覧・プレビュー本文は画面全体を固定したまま各枠内で縦スクロール可能。印刷時のA4レイアウトは維持。
- モーラ練習UIを再構成。手拍子／画面タップ、拍の視覚表示、カウント、回数確認、4択、判定・次へを一画面に集約。
- 縦向きは上下を使う配置、横向きは左右2カラム配置。

Android Studio実ビルド、実機マイク・印刷の最終確認は別途必要です。
