# Kotoba Quest Web V82

V81を基準に、モーラ練習のスタイル選択を2種類に整理し、動きのあるゲーム風演出を追加しました。

## モーラ練習のスタイル
- 手拍子：マイク入力で手拍子の音を検出します。
- 画面タップ：画面上のボタンで1拍ずつ数えます。マイクは不要です。

V81の「テーブルタップ」は、手拍子と同じマイク音声検出を使っていたため、独立した選択肢から削除しました。

## 演出の変更
- MORA QUESTのミッションゲートに、回転する軌道・スキャン光・発光ノードを追加。
- 2枚のスタイルカードに、浮遊・光の走査・波形・タップ波紋のアニメーションを追加。
- カード選択時は選択したカードを強調し、回転リングとロード演出を表示してからモーラ問題に遷移。
- モーション低減設定が有効な端末ではアニメーションを抑制します。

## セッション動作
最初に2つのスタイルから1つを選び、その回のモーラ練習中は同じスタイルを継続します。全問終了後に選択状態がリセットされ、次の開始時には再び選択画面を表示します。

## ファイル名・文字コード
ZIP内のフォルダー名・ファイル名はASCII文字を使用しています。テキストファイルはUTF-8で保存しています。

## 確認
JavaScript構文チェック、ZIP整合性、ファイル名・UTF-8読み込みを確認しています。マイク検出と演出の実機確認は別途必要です。
