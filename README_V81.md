# ことばクエスト Web版 V81

V80をベースに、モーラ練習の開始演出とスタイル選択の流れをゲームアプリ風に変更しました。

## モーラ練習の流れ
1. モーラ練習を開始すると、最初に「MORA QUEST｜スタイル選択」画面が表示されます。
2. 「手拍子」「テーブルタップ」「画面タップ」の3枚のカードから、今回使う方法を1つ選びます。
3. カード選択後に選択確定・フラッシュ・スタイル登場演出が表示され、モーラ問題が始まります。
4. 選んだ方法は、今回のトレーニング中のすべての問題で継続します。問題ごとに選び直す必要はありません。
5. 全問題終了後に選択状態はリセットされます。再挑戦すると、再び3つのカードから選択します。

## 確認事項
- 手拍子：マイク入力で音を検出します。
- テーブルタップ：マイクが机を叩く音を検出します。端末の加速度センサーで振動を直接測定する機能ではありません。
- 画面タップ：画面ボタンで1拍ずつ数えます。マイクは不要です。
- 実機のマイク感度、表示演出、Android端末での動作は実機テストが必要です。

HTTPSまたはlocalhostでの利用を推奨します。
